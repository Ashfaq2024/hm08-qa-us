This project involved writing automated end-to-end tests for Urban Routes, ensuring the smooth functionality of the taxi ordering process. The tests covered setting the address, selecting a supportive plan, entering a phone number, adding a credit card, writing a message for the driver, and ordering additional items like a blanket, handkerchiefs, and ice creams. A key challenge was handling UI interactions, such as waiting for the car search modal and verifying the driver assignment process.
